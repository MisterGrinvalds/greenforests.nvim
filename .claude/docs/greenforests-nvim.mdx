# greenforests.nvim

> A production-ready Neovim configuration emphasizing modularity, productivity, and seamless AI + terminal integration.

| | |
|---|---|
| **Repository** | [MisterGrinvalds/greenforests.nvim](https://github.com/MisterGrinvalds/greenforests.nvim) |
| **Plugin Manager** | lazy.nvim |
| **Theme** | Catppuccin Mocha |
| **Font** | Nerd Font compatible |

## Architecture

```
lua/
├── core/           # Core settings and plugin manager
├── plugins/        # 24 plugin specification files
├── lib/            # Custom modules (forks, help system)
├── custom/         # Standalone implementations (tmux, tab-picker)
└── greenforests/   # Package health checks
```

## Core Modules

### options.lua
Vim options and settings:
- Relative line numbers with absolute current line
- Mouse enabled, system clipboard sync
- Persistent undo across sessions
- Smart case-insensitive search
- Sign column always visible
- 10-line scrolloff
- Live substitution preview

### keymaps.lua
Non-plugin keymaps:
| Keymap | Action |
|--------|--------|
| `<Esc>` | Clear search highlights |
| `<leader>w` | Save file |
| `<A-j/k>` | Move line down/up |
| `</>/` (visual) | Indent and reselect |
| `<leader>tt/to/tc` | Terminal toggle/open/close |
| `<X1Mouse>/<X2Mouse>` | Jump back/forward (mouse) |

### autocmds.lua
- Highlight text on yank

### lazy.lua
- lazy.nvim bootstrap and plugin loading
- Nerd Font icon fallbacks

## Custom Modules

### lib/forks.lua
Transforms plugin URLs to personal fork format (`MisterGrinvalds/owner.repo`).

### lib/plugin-help.lua
Interactive help system with:
- Plugin registry with keymaps, commands, tips
- Telescope-based plugin picker
- Floating window help display

**Commands:**
- `:PluginHelp [name]` - Show plugin documentation
- `:PluginKeymaps` - Browse all keymaps
- `:PluginCategories` - Show plugins by category
- `:KeymapGuide` - Quick reference

### custom/tmux/
Complete tmux integration:
- Window/session management
- Telescope picker for windows
- Send commands/selections

### custom/tab-picker.lua
Telescope picker for Vim tabs with create/rename/delete.
